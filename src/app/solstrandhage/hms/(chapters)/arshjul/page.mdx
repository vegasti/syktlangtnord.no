# Årshjul for HMS-arbeidet

| Måned | Oppgave | Ansvar |
| --- | --- | --- |
| Januar | Kontroll av snølast på tak. Visuell sjekk av utelys og gangveier. | Styret |
| Februar | Gjennomgang av vintervedlikehold — vurdere behov for ekstra strøing/brøyting. | Styret |
| Mars | Planlegging av vernerunde og eventuelle utbedringer til våren. | Styret |
| April | Vernerunde — fellesarealer, bygg, lekeplass. Oppstart av sommervedlikehold. | Styret / dugnad |
| Mai | Årlig kontroll av lekeplass (fagperson). Vårdugnad. Årsmøte. | Styret + fagperson |
| Juni | Test av utebelysning og kontroll av carport-anlegg. | Styret |
| Juli | Ferie — løpende avvikshåndtering. | Styret |
| August | Forberedelse til Nasjonal brannøvelse. Informasjon til beboere. | Styret |
| September | Nasjonal brannøvelse. Test av røykvarslere. | Alle beboere |
| Oktober | Høstdugnad. Klargjøring for vinter (strøkasser, brøyteavtale). | Styret / dugnad |
| November | Kontroll av fasade, takrenner og takstein. Bestill snøbrøyting. | Styret |
| Desember | Årlig gjennomgang av HMS-planen. Oppdatering før nytt år. | Styret |

## Lengre intervaller

| Frekvens | Oppgave | Ansvar |
