# Sjekkliste for vernerunde

Gjennomføres minst én gang årlig.

## Brannvern

- [ ] Rømningsveier ryddige (trapp, ganger, inngangspartier)
- [ ] Brannmerking/branninstruks synlig på fellesareal
- [ ] Slokkeutstyr på fellesområder (hvis aktuelt) kontrollert
- [ ] Ingen brannfarlig vare oppbevart i boder/carport

## Elektrisk anlegg

- [ ] Utelys virker på alle fellesområder
- [ ] El-anlegg i carport uten synlige skader
- [ ] Sikringsskap i fellesområde uten varme/lukt/tegn til feil
- [ ] El-kontroll innenfor 5-års intervall

## Lekeplass

- [ ] Lekeapparater uten skader, splinter eller ustabilitet
- [ ] Fallunderlag i orden
- [ ] Ingen farlige gjenstander eller avfall på lekeplassen
- [ ] Årlig fagkontroll gjennomført siste 12 mnd.

## Uteområde / bygningsmasse

- [ ] Gangveier uten snubleniner, hull eller knuste heller
- [ ] Takrenner, nedløp og takstein uten synlige skader
- [ ] Fasade uten skader eller løse elementer
- [ ] Gjesteparkering ryddig og godt merket
- [ ] Skilting og informasjon oppdatert

## Vinter (oktober–april)

- [ ] Strøkasser fylt og tilgjengelige
- [ ] Brøyteavtale aktiv og fungerende
- [ ] Ingen åpenbar rasfare fra tak
- [ ] Snølast på tak innenfor forsvarlig nivå
